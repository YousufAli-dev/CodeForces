Problem Link : https://codeforces.com/problemset/problem/1903/A
Problem Name : A. Halloumi Boxes 1903A
Logic:

If k == 1, we can’t rearrange — so array must already be sorted.

If k > 1, we can always rearrange the array into sorted order (since overlaps allow free movement of elements).

Complexity:

Time: O(n) per test case

Space: O(n)
